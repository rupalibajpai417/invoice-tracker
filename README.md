# 🧾 Invoice Tracker

A full stack web application for freelancers and small businesses 
to create invoices, track payments, and manage clients — 
all in one place.

## 🚀 Tech Stack
- **Frontend:** React + TypeScript
- **Backend:** Java Spring Boot
- **Database:** PostgreSQL
- **Auth:** JWT Tokens
- **Deployment:** Docker + Render
- **CI/CD:** GitHub Actions

## ✨ Features
- [ ] Create and manage invoices
- [ ] Track payment status (unpaid / paid / overdue)
- [ ] Client management
- [ ] Automatic overdue reminders
- [ ] Revenue dashboard with analytics
- [ ] PDF invoice generation
- [ ] Secure login with JWT authentication

## 🏗️ Project Status
> Currently in development — built as a full stack learning project.
